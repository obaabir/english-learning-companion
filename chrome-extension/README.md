# English Companion – Chrome extension

Select English text in Chrome and send it to the **English Learning Companion** app (Articles section),
where it is explained, can be discussed in the chat and saved — like subtitles coming from VLC.

Free: it is loaded straight from this folder (no Chrome Web Store, no payment).

## Install (once)

1. Open Chrome and go to `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose this `chrome-extension` folder.
4. (Optional) Pin it: puzzle icon → pin **English Companion**.

## Use

- Keep the English Learning Companion app open.
- In Chrome, select a word or sentence → press **✨ Explain** (or right-click → **Explain in English Companion**, or **Alt+Shift+E**).
- The app opens Articles with the text, its sentence and the page, and explains it. The article is added to your reading history.

## Privacy

The extension sends the selected text, its sentence/paragraph, the page title and address, and the page's readable article
text **only to `127.0.0.1` (your own computer)**. Nothing is sent to the internet. The app accepts these requests only from
a browser extension, not from web pages.
